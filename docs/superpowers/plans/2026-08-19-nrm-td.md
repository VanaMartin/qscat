# Time-Dependent Nonlocal Resonance Model — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Propagate the nonlocal resonance model's nuclear wave packet and
extract `σ_DA(E)` and `σ_{v→v'}(E)` for N₂, F₂ and NO, gated against the
time-independent `qscat.core.nrm` as an exact differential oracle.

**Architecture:** The memory integral of Gertitschke & Domcke Eq. (2.1) is
resummed into a time-local coupled system by introducing one auxiliary nuclear
packet per projected electronic state. Propagation is therefore ordinary
Schrödinger evolution under a sparse, arrow-shaped, complex-symmetric block
Hamiltonian, driven by the existing order-3 Padé stepper. The half-Fourier
transform of the propagated discrete-state block *is* the time-independent
`Ψ_d(R;E)`, so every downstream extraction step is existing tested code.

**Tech Stack:** Python 3.12, numpy/scipy sparse, `qscat.evolution.make_pade_stepper`,
`qscat.linalg.SparseLU`, `qscat.core.nrm` (TI), pytest.

**Spec:** `docs/superpowers/specs/2026-08-19-nrm-td-design.md`

## Global Constraints

- **Atomic units throughout** (`qscat.units`). Gertitschke & Domcke work in
  eV/Å/fs; no constant from its parameter tables is carried into this code.
- **The published papers are the sole specification.** PRA 77, 012710 (2008)
  (`reference/literature/houfek-2008-pra77-012710.md`) and PRA 47, 1031 (1993)
  (`reference/literature/gertitschke-1993-pra47-1031.md`). Every equation
  reference in code names its paper and equation number.
- **`reference/eMoScat/source/module_NRM.cpp` specifies nothing.** No code may
  be justified by "eMoScat does it this way"; no test may assert agreement
  with it.
- **`qscat.core` never imports `qscat.model` or `projects` at runtime** — only
  the `ResonanceModel` protocol, under `TYPE_CHECKING`. Enforced by
  `libs/qscat/tests/test_core_no_model_import.py`.
- **ECS ⇒ bilinear c-product.** Inner products of two wavefunction-like vectors
  use `qscat.linalg.c_product` and carry no conjugation. `np.conjugate` and
  `.conj().T` are permitted **only** for a probability density over the real
  region (`|ψ|²`, the diagnostics of Task 4), and every such use carries a
  comment saying why it is not a c-product.
- **Coefficient space.** Everything is DVR coefficients (`c_j = f(x_j)√w_j`);
  Eq. (60)'s `√W` factors are already absorbed, per
  `nonlocal_potential.py`'s module docstring. Never re-apply weights.
- **Sparse transposes use `.T`, never `.conj().T`** — the block Hamiltonian is
  complex *symmetric*, not Hermitian.
- `uv run ruff check .` clean; `uv run mypy libs/qscat/qscat` clean.
- Tests costing more than ~10 s are `@pytest.mark.slow`.

def test_eliminating_the_arms_reproduces_the_nonlocal_operator(nuc, ing):
    """(E - H_ext)^-1 restricted to the d-block IS (E - T - V_d - F(E))^-1.

    This is the whole design: the extended space is a RESUMMATION of Eq.
    (2.1), not an approximation of it, so the two resolvents must agree to
    solver precision -- no physics tolerance is involved.
    """
    e_total = 0.05
    n_r = nuc.n
    h_ext = extended_hamiltonian(ing, nuc, F2, n_states=N_STATES)
    a_ext = (e_total * sp.identity(h_ext.shape[0], dtype=np.complex128) - h_ext).tocsc()

    rhs = np.zeros((h_ext.shape[0], n_r), dtype=np.complex128)
    rhs[:n_r, :] = np.eye(n_r, dtype=np.complex128)
    d_block = np.asarray(spsolve(a_ext, rhs))[:n_r, :]

    f = nonlocal_operator(ing, nuc, F2, e_total, n_states=N_STATES)
    v_d = continue_to_tail(ing.v_d_discrete, ing.R, nuc)
    a_ti = (
        e_total * np.eye(n_r, dtype=np.complex128)
        - kinetic(nuc, F2.mu)
        - np.diag(v_d)
        - f
    )
    assert np.allclose(d_block, np.linalg.inv(a_ti), rtol=1e-8, atol=1e-12)

    h = extended_hamiltonian(ing, nuc, F2, n_states=N_STATES)

```python
# libs/qscat/qscat/core/nrm/extended.py
"""The extended-space (time-local) form of the nonlocal resonance model.

Gertitschke & Domcke, Phys. Rev. A 47, 1031 (1993), Eq. (2.1) is a memory
integral. It does not have to be evaluated as one. The kernel this package
builds (`nonlocal_potential.nonlocal_operator`, PRA 77 Eq. 60-61) is a sum of
resolvents,

    F(E) = sum_n diag(V_dn) (E - H_n)^-1 diag(V_dn),
    H_n  = T_R + V_0(R) + E_n(R)

so introducing one auxiliary nuclear packet `phi_n` per projected electronic
state turns Eq. (2.1) into a time-LOCAL coupled system,

    i d/dt Psi_d = (T_N + V_d) Psi_d + sum_n V_dn phi_n
    i d/dt phi_n = H_n phi_n + V_dn Psi_d

i.e. propagation under one arrow-shaped block Hamiltonian. Eliminating the
`phi_n` from the time-independent version returns PRA 77 Eq. (52) with exactly
the `F(E)` above -- this is a RESUMMATION of Eq. (2.1), not an approximation
of it, and `test_nrm_extended.py` gates that identity.

SYMMETRY: under ECS the matrix is complex SYMMETRIC, not Hermitian. Every
transpose here is `.T`; a `.conj().T` would silently produce a different
operator.
"""

from __future__ import annotations

from typing import TYPE_CHECKING

import numpy as np
import numpy.typing as npt
import scipy.sparse as sp

from qscat.dvr import FemDvrEcsGrid, kinetic_sparse

from .ingredients import NrmIngredients
from .nonlocal_potential import (
    TAIL_COUPLING_MAX,
    check_nodes_coincide,
    continue_to_tail,
)

if TYPE_CHECKING:
    from qscat.model import ResonanceModel

__all__ = ["extended_hamiltonian"]


def extended_hamiltonian(
    ing: NrmIngredients,
    nuclear_grid: FemDvrEcsGrid,
    model: ResonanceModel,
    *,
    n_states: int | None = None,
) -> sp.csr_matrix:
    """The arrow block Hamiltonian of the module docstring.

    Block 0 (rows/columns `0:N_R`) is the discrete state; block `k+1` is
    projected electronic state `k`, in `ing`'s own adiabatic-tracking order.

    Raises
    ------
    ValueError
        If `n_states` is outside `[0, ing.E_n.shape[1]]`, if `ing.R` does not
        coincide with the grid's real DVR nodes, or if a projected state
        carries appreciable coupling into the ECS tail (the same Eq. (67)
        guard `nonlocal_operator` applies, for the same reason).
    """
    n_avail = ing.E_n.shape[1]
    n_use = n_avail if n_states is None else int(n_states)
    if n_use > n_avail or n_use < 0:
        raise ValueError(f"n_states={n_states} outside the available range [0, {n_avail}]")
    check_nodes_coincide(ing.R, nuclear_grid)

    t_nuc = kinetic_sparse(nuclear_grid, model.mu)
    v0 = np.asarray(model.v0(nuclear_grid.points), dtype=np.complex128)
    v_d = continue_to_tail(ing.v_d_discrete, ing.R, nuclear_grid)
    tail = nuclear_grid.points.imag != 0.0

    h_d = (t_nuc + sp.diags(v_d)).tocsr()
    if n_use == 0:
        return h_d

    arms: list[sp.csr_matrix] = []
    couplings: list[sp.csr_matrix] = []
    for n in range(n_use):
        v_dn = continue_to_tail(ing.V_dn[:, n], ing.R, nuclear_grid)
        tail_coupling = np.max(np.abs(v_dn[tail])) if np.any(tail) else 0.0
        if tail_coupling > TAIL_COUPLING_MAX:
            raise ValueError(
                f"state {n} carries coupling {tail_coupling:.3g} into the ECS "
                "tail; the discrete state does not satisfy Eq. (67) on this grid"
            )
        e_n = continue_to_tail(ing.E_n[:, n], ing.R, nuclear_grid)
        arms.append((t_nuc + sp.diags(v0 + e_n)).tocsr())
        couplings.append(sp.diags(v_dn).tocsr())

    coup = sp.hstack(couplings, format="csr")  # (N_R, n_use * N_R)
    out: sp.csr_matrix = sp.bmat(
        [[h_d, coup], [coup.T, sp.block_diag(arms, format="csr")]],
        format="csr",
        dtype=np.complex128,
    )
    return out
```

Import note: `_TAIL_COUPLING_MAX` and the tail-guard block are module-private

    single factorization; this is the property that makes that legal.

  `.energies (n_E,)`, `.e_total (n_E,)`, `.truncation_error float`.

**Why there is an SVD here at all.** PRA 47 Eq. (2.5)'s launch state
`V_dk_i(R) χ_v(R)` depends on the incident energy, and Eq. (2.17) removes that
dependence only under the separability of Eq. (2.16), which these models do not
satisfy exactly. They satisfy it *numerically*: measured 2026-08-19 for choice
B, the singular values of `M[R, E_j]` normalized to the first are
1, 5.7e-3, 2.4e-4, 5.3e-7 on F₂'s DA window (0.010-0.050 Ha) and
1, 9.8e-4, 1.2e-6, 1.1e-8 on N₂'s VE window (0.060-0.160 Ha). So the left
singular vectors are propagated and every energy is reconstructed by linearity
of the resolvent — `r ≈ 3` columns instead of `n_E`, with `r = 1` reproducing
Eq. (2.17) exactly.

`r` is chosen from `rank_tol`, never hardcoded. `truncation_error = σ_{r+1}/σ_1` is
carried so the propagation can report the economy's cost.

@dataclass(frozen=True)
class LaunchBasis:
    vectors: npt.NDArray[np.complex128]   # (N_ext, r), arm blocks zero
    coeffs: npt.NDArray[np.complex128]    # (r, n_E)
    energies: npt.NDArray[np.float64]     # (n_E,) incident kinetic energies
    e_total: npt.NDArray[np.float64]      # (n_E,) transform frequencies
    truncation_error: float               # sigma_1-relative, NOT per-energy

    @property
    def rank(self) -> int:
        return int(self.vectors.shape[1])


def initial_packet(nuclear_grid, elec_grid, model, phi_d, ing, eps, chi, v_init,
                   energies, *, n_states=None, rank_tol=1e-6):
    """PRA 47 Eq. (2.5) `Psi_d(R,0) = V_dk_i(R) chi_v(R)`, factorized.

    The launch matrix `M[R, j]` is SVD'd and truncated at `rank_tol`; the left
    singular vectors are what Task 3 propagates, and `coeffs` reconstructs
    every energy from them. `rank_tol=0.0` keeps every mode (no truncation).

    PRA 47 Eq. (2.17) removes the energy dependence analytically, but only
    under Eq. (2.16)'s separability, which these models do not have exactly.
    Rank 1 here IS Eq. (2.17); higher ranks are the controlled generalization.
    """
    e = np.atleast_1d(np.asarray(energies, dtype=np.float64))
    if np.any(e <= 0.0):
        raise ValueError("incident energies must be positive")
    n_avail = ing.E_n.shape[1]
    n_use = n_avail if n_states is None else int(n_states)
    n_r = nuclear_grid.n

    m = np.empty((n_r, e.size), dtype=np.complex128)
    for j, e_kin in enumerate(e):
        v_dk_i = continue_to_tail(
            v_dk_plus(elec_grid, model, phi_d, ing.R, float(e_kin)), ing.R, nuclear_grid
        )
        m[:, j] = v_dk_i * chi[v_init]

    u, sv, vh = np.linalg.svd(m, full_matrices=False)
    keep = sv.size if rank_tol <= 0.0 else max(1, int(np.sum(sv > rank_tol * sv[0])))
    truncation_error = float(sv[keep] / sv[0]) if keep < sv.size else 0.0

    vectors = np.zeros(((1 + n_use) * n_r, keep), dtype=np.complex128)
    vectors[:n_r, :] = u[:, :keep]
    coeffs = sv[:keep, None] * vh[:keep, :]
    return LaunchBasis(vectors=vectors, coeffs=coeffs, energies=e,
                       e_total=e + float(eps[v_init]),
                       truncation_error=truncation_error)
```

`eps` sits beside `chi` exactly as it does on the TI entry points, and is used
only for `e_total = energies + eps[v_init]`. **The SVD is of the raw launch
matrix, not of a normalized one** — truncating by relative singular value

- Produces: `TdNrmResult` and `propagate_nrm(h_ext, launch, nuclear_grid,

  `(N_R, n_E)` and `.rank` the number of columns actually stepped.

**The transform, derived.** For `i ∂_t Ψ = H_ext Ψ` with `Ψ(0)` given,
integrating `∫_0^∞ dt e^{i(E+i0)t}` by parts and killing the `t→∞` boundary
term by ECS absorption gives `(E − H_ext) Ψ̂ = i Ψ(0)`, hence

```
Ψ_d^TI(R;E) = −i ∫_0^∞ dt e^{iEt} Ψ_d(R,t)
```

`r` singular-vector columns are stepped (Task 2). The per-energy packet
`Psi_d(R,t;E_j) = Sum_m coeffs[m,j] U_m(R,t)` is reconstructed each step and
fed to both the transform and the diagnostics, so the accumulator is
`(N_R, n_E)` and no snapshot history is stored.

# libs/qscat/qscat/core/nrm/propagation.py  (implementation sketch -- the
# module docstring must carry the by-parts derivation of the -i prefactor)

@dataclass(frozen=True)
class TdNrmResult:
    psi_d: npt.NDArray[np.complex128]      # (N_R, n_E) -- Psi_d(R;E)
    time: npt.NDArray[np.float64]          # (n_steps+1,)
    survival: npt.NDArray[np.float64]      # (n_steps+1, n_E)
    centroid: npt.NDArray[np.float64]
    momentum: npt.NDArray[np.float64]
    unabsorbed: npt.NDArray[np.float64]    # (n_E,) packet norm still in the
                                           # real region at t_max


def propagate_nrm(h_ext, launch, nuclear_grid, *, dt, n_steps, order=3):
    e = launch.e_total
    psi = np.asarray(launch.vectors, dtype=np.complex128)   # (N_ext, r)
    coeffs = launch.coeffs                                   # (r, n_E)
    n_r = h_ext.shape[0] if nuclear_grid is None else nuclear_grid.n
    step = make_pade_stepper(h_ext, dt, order)
    w = quadrature_weights(n_steps + 1)
    t = dt * np.arange(n_steps + 1)

    acc = np.zeros((n_r, e.size), dtype=np.complex128)
    survival = np.empty((n_steps + 1, e.size))
    centroid = np.empty_like(survival) if nuclear_grid is not None else np.empty((0, 0))
    momentum = np.empty_like(centroid)
    deriv = _real_derivative_matrix(nuclear_grid) if nuclear_grid is not None else None

    for m in range(n_steps + 1):
        # Reconstruct the per-energy packet from the r propagated columns --
        # legal because H_ext is energy-independent, so the superposition
        # commutes with the propagator.
        d = psi[:n_r, :] @ coeffs                            # (N_R, n_E)
        acc += (w[m] * dt) * np.exp(1j * e * t[m])[None, :] * d
        _record(m, d, nuclear_grid, deriv, survival, centroid, momentum)
        if m < n_steps:
            psi = step(psi)

    return TdNrmResult(psi_d=-1j * acc, time=t, survival=survival,
                       centroid=centroid, momentum=momentum,
                       unabsorbed=survival[-1].copy(), rank=launch.rank)
```

Diagnostics (`_record`), on the real region only — PRA 47 Eq. (4.4)-(4.6):

```python
# CONJUGATION NOTE: these are probability densities over the REAL region, not
# c-products. |psi|^2 is the physically meaningful quantity there; the complex
# tail is an absorber and is excluded by the mask. This is the one place in
# the package where np.conjugate is correct.
mask = nuclear_grid.real_points <= nuclear_grid.R0
dens = np.abs(d[mask, :]) ** 2
s = dens.sum(axis=0)
survival[m] = s
centroid[m] = (nuclear_grid.real_points[mask, None] * dens).sum(axis=0) / s
momentum[m] = np.real(
    (np.conjugate(d[mask, :]) * (-1j * (deriv @ d))[mask, :]).sum(axis=0) / s
)
```

`_real_derivative_matrix(grid)` stacks `qscat.dvr.dvr_first_derivative_at_node(
grid, i)` over the real nodes (that function requires
`grid.real_points[i] <= grid.R0`), cached per grid via `functools.lru_cache`
on `id(grid)` — or built once per `propagate_nrm` call, which is simpler and
costs `O(N_R²)` once. Prefer the simple version.

`⟨P⟩_t` is a diagnostic only. If `dvr_first_derivative_at_node` turns out not
to compose into a usable matrix here, return an empty `momentum` array and
report that in the task report rather than inventing a finite-difference
stand-in — nothing downstream consumes it.
