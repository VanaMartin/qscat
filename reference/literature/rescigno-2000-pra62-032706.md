# T. N. Rescigno, C. W. McCurdy, Phys. Rev. A 62, 032706 (2000) — Numerical grid methods for quantum-mechanical scattering problems

**Source:** `reference/literature/rescigno-2000-pra62-032706.pdf` (gitignored) · DOI 10.1103/PhysRevA.62.032706
**Pagination:** per-article, 032706-1 … 032706-8 (extractor page N = printed page 032706-N; offset zero, checked at page 1 and page 8).

## Why this repository cares

This is the paper that introduced the FEM-DVR-ECS method itself — combining
the finite-element method with the discrete variable representation, and
applying exterior complex scaling at a sharp finite-element boundary rather
than a smoothed contour. `qscat.dvr` (`grid.py`, `kinetic.py`, `gll.py`,
`operators.py`) and `qscat.ecs.ecs_map` are a direct implementation of the
construction given here: the Gauss-Lobatto quadrature and Lobatto shape
functions, the bridge functions that stitch elements together, the
Scrinzi–Elander kinetic-energy matrix element that sidesteps the
discontinuous-derivative subtlety at element boundaries, and the ECS
coordinate map applied exactly at an element boundary. Without this source,
`qscat.dvr`'s grid construction and kinetic-energy assembly would be
unattributed numerics rather than a validated method.

Atomic units throughout (`m = e = ħ = 1`, p. 032706-5) — the same convention
`libs/qscat/qscat/units.py` uses; no conversion needed. The paper's Sec. IV
numerical examples (Eqs. 28-49, the free-particle-breakup and short-range
two-electron model problems) are standalone benchmarks for the method and are
not themselves reused by this repo — see Not used here.

## Parameters and numeric values

No model parameters (masses, potential constants) are published here — this
is a methods paper, not a molecular-model paper. The one numeric table
(Table I, p. 032706-6: wave-function convergence vs. `n` and `R0`) is the
paper's own internal convergence demonstration, not a value the repo checks
against; not applicable to compare against repo code.

## Findings and limits

- The FEM-DVR combination requires no smoothing of the ECS rotation contour,
  unlike Karlsson's earlier DVR-with-smooth-complex-mapping approach — sharp
  scaling at a finite-element boundary "has [been found to have] no numerical
  difficulties" — p. 032706-5, end of Sec. III. This is the paper's central
  methodological claim and the one `qscat.dvr`/`qscat.ecs` rely on most
  directly: `docs/physics/femdvr-ecs.md`'s "Method" section states the same
  single-shared-angle, node-aligned design without smoothing.
- Convergence in the number of DVR functions per element is rapid: `n=10`
  already visually matches `n=18` in the paper's own comparison
  (Fig. 2, p. 032706-6); `n=18` converges the tested wave function to six
  significant figures — p. 032706-6.
- Moving the ECS radius `R0` from 50 to 60 bohr (Table I) changes the
  converged wave-function value only in the fourth significant figure at
  low `n` and not at all by `n=14` — the paper's own evidence that the
  discontinuous change in contour slope at `R0` introduces no numerical
  pathology when `R0` sits on a node, as the method requires.
- The paper's own stated scope: the numerical examples are 2-D two-particle
  breakup/short-range models illustrating the method in general, not a
  resonant-collision or diatomic-molecule application — that model
  (`V(R,r)`, the FEM-DVR-ECS grid applied to a nuclear + electronic
  coordinate pair) is introduced later, in Houfek/Rescigno/McCurdy (2006);
  see `reference/literature/houfek-2006-pra73-032721.md`. This paper is
  cited by that one (their Eq. 27-28's ECS map) as the numerical-method
  foundation.
- Stated future applications (p. 032706-8, Sec. V "Discussion"): bound and
  resonance states, and chemical reaction dynamics, in addition to the
  electron-impact-ionization breakup problems this paper itself solves.

## Terminology map

| Paper symbol | qModeling name |
|---|---|
| `r_i` (FEM nodes) | element boundaries, `GridSpec.elements` / `ar` in `qscat.dvr.grid.FemDvrEcsGrid` |
| `f_{i,m}(x)` (Lobatto shape function, unnormalized) | not named separately; folded into `gll.diff_matrix`'s collocation derivative |
| `chi_{i,m}(x)` (normalized bridge/basis function) | the implicit DVR basis; the repo works directly with `points`/`weights`/`dLp`, not an explicit basis-function object |
| `R0` (ECS radius, must be a FEM node) | `GridSpec.R0` / `FemDvrEcsGrid.R0` |
| `phi` (ECS rotation angle) | `theta_deg` in `qscat.ecs.ecs_map` and `ElementSpec.angle_deg` |
| `T_{m,m'}^{i,i'}` (kinetic-energy matrix element) | `qscat.dvr.kinetic.kinetic`'s per-element `T_local` block, scatter-summed |
| `Phi_0`, `Psi_sc`, `Psi_+` (unperturbed/scattered/total wave) | same driven-equation split used by `qscat.core.driven.ve_cross_section` (see `houfek-2006-pra73-032721.md`'s Eq. 14 for the diatomic-specific form) |

The paper's Eq. (20) gives the Lobatto shape-function derivative in an
explicit product formula; `qscat.dvr.gll.diff_matrix` computes the equivalent
collocation-derivative matrix via barycentric weights instead (a numerically
robust reformulation of the same underlying object, not transcribed
literally) — not checked for bit-for-bit formula correspondence, only for
matching output via the particle-in-a-box benchmark (`B1`,
`libs/qscat/tests/test_femdvr_ecs.py`, see `docs/physics/femdvr-ecs.md`).

## Not used here

- Sec. IV's worked numerical examples in full (the analytic free-particle
  s-wave breakup Green's function, Eqs. 28-40; the two-electron short-range
  exponential-potential model, Eqs. 41-49; the optical-theorem and
  projected-optical-theorem cross-section formulas, Eqs. 45-46; the
  single-differential energy-sharing breakup cross section, Eqs. 48-49) —
  read for the method's validation, not reused as a repo benchmark or
  formula source. `qscat.dvr`'s own benchmarks (particle-in-a-box, harmonic
  oscillator, ECS continuum rotation, bound-state theta-independence) are
  independent analytic oracles, not ports of this paper's examples.
- The FEM-DVR scaling/cost argument (nonzero-element counts, the `N/n`
  speedup ratio, p. 032706-4) — background motivation only, not something
  the repo measures or cites for its own sparse-matrix performance claims
  (`docs/physics/mumps-sparse-backend.md` and related notes use independently
  measured repo numbers).
- Figs. 1-5 (Lobatto shape-function plot, wave-function/cross-section plots
  for the two worked examples) — read for qualitative confirmation only; no
  data extracted.
- The `1050-2947/2000/62(3)/032706(8)` APS boilerplate, author affiliations,
  and acknowledgments carry no technical content for this repo.
