handoffs, progress snapshots, renderer/tests and dated PNG/SVG figures. Every
member was freshly downloaded from the public store and checked byte-for-byte
against its original tracked source before superseded figures were removed from
the working tree. The archive is 93,307,293 bytes, SHA256
`1c09411aebf941fe5ecb8688af49749dee1600fea85f652bb6f310ec7eb91bea`.

```sh
uv run qscat-run fetch projects/ukrmol_co/qualification-evidence/campaign-history
```

`members.json` lists each original repository path, size and SHA256. Extract the
archive outside the checkout. The original complete source is also retained in
Git history; the archive is not a substitute for scientific raw-result bundles.

their original instant. **They do not release current execution.** Failed exits
and rejected gates remain failed even when a later distinct release passed.
